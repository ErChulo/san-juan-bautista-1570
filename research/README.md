# Research source pack

This folder provides a machine-readable source index for the historical-geography site.

The website distinguishes three categories:

1. **Primary or archival records** — especially the 1519 PARES record concerning islands to be annexed to the bishopric of San Juan.
2. **Historical publications** — including Salvador Brau and Juan López de Velasco.
3. **Historical maps** — used as research context, not as the geometric basis for the modern area or distance calculations.

The actual historical scans remain hosted by the custodial institutions (PARES, Library of Congress, Biblioteca Virtual Banco de la República / Miguel de Cervantes). This avoids duplicating large archival files while preserving stable provenance and rights information.

See `sources.csv` for URLs, download/access links, dates, institutions, and usage notes.
