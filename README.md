# San Juan Bautista del Boriquén en 1570

Sitio divulgativo que resume y complementa el video de El Boricuazo sobre la extensión insular vinculada a San Juan Bautista del Boriquén hacia 1570.

## Criterio editorial

- El relato principal conserva el conteo de **22 islas o unidades** presentado en el video.
- Las notas técnicas distinguen entre la narración del video, la documentación histórica y la normalización geográfica moderna.
- La base histórica principal incluye la Real Cédula de **15 de enero de 1519** conservada en PARES sobre la anexión de islas al obispado de San Juan.
- Las superficies son áreas terrestres modernas usadas como aproximación física; no se presentan como mediciones efectuadas en 1570.
- La distancia Monito–Dominica se calcula geodésicamente sobre WGS-84.

## Resultados principales

- Conteo narrativo: **22 unidades**
- Superficie moderna normalizada: **5,011.783 mi²**
- Monito → Dominica: **475.405 mi**
- Monito → Dominica: **765.090 km**
